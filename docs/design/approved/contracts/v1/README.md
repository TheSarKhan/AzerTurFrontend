# Müqavilə modulu — dizayn təklifi

Status: istifadəçi tərəfindən təsdiqlənib. Bu fayllar vizual konseptdir; tətbiq ayrı repolarda hazırlanır.

- operator-desktop.png: operator PDF əlavə edir, təkliflə əlaqəsini yoxlayır və göndərir.
- customer-desktop.png: müştəri sənədə baxır və ayrıca təsdiq edir.
- customer-mobile.png: müştərinin mobil müqavilə icmalı və PDF baxışı.

Maketlərdəki bütün məlumatlar nümunədir. Süni yaradılmış PDF mətnləri, şirkət adı, tarixlər, son etibarlılıq tarixi və “signed contract” ifadəsi biznes və ya hüquqi tələb kimi qəbul edilmir. Real müqavilə mətni şirkət tərəfindən təqdim ediləcək. PDF-in əvvəlcədən imzalanması nəzərdə tutulmur.

Tətbiq zamanı: operator yalnız düzgün təklif versiyasına bağlı sənədi göndərir; müştəri yalnız öz sənədini açıb nəzərdən keçirdikdən sonra ayrıca təsdiq edir. Təsdiq dəqiq PDF versiyasına, istifadəçiyə və vaxta bağlanır. Yeni versiya ayrıca təsdiq tələb edir. Ödəniş ayrıca mərhələdir; xidmətlər üzrə ləğv qaydaları müvafiq sənədlə müəyyənləşir. Tətbiq olunmuş funksionallıq bu maketlərdən ayrıca yoxlanmalıdır.

Figma Community fayllarına birbaşa çıxış məhdud idi; istinad olaraq layihədə əvvəl təsdiqlənmiş müştəri kabineti və operator təklifi dizaynlarından istifadə edilib.
